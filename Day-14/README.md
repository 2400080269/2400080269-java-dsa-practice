# Day 14 — Selection and insertion sort

## What to push
- `SelectionInsertionSort.java` — complete Java practice program.
- This README — concept and learning notes.

## Concept
Selection sort selects the smallest remaining value. Insertion sort inserts each value into its sorted left portion.

## How to run
Open a terminal in this folder and run:

```bash
javac SelectionInsertionSort.java
java SelectionInsertionSort
```
