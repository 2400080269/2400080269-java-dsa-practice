# Day 13 — Bubble sort

## What to push
- `BubbleSort.java` — complete Java practice program.
- This README — concept and learning notes.

## Concept
Compare adjacent elements and swap them when they are out of order. Average/worst time: O(n^2).

## How to run
Open a terminal in this folder and run:

```bash
javac BubbleSort.java
java BubbleSort
```
