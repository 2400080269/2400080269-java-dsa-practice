# Day 10 — Reverse an array

## What to push
- `ReverseArray.java` — complete Java practice program.
- This README — concept and learning notes.

## Concept
Use two pointers and swap the outer elements until the pointers meet. Time: O(n), extra space: O(1).

## How to run
Open a terminal in this folder and run:

```bash
javac ReverseArray.java
java ReverseArray
```
